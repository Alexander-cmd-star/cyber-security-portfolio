## 📂 Мои проекты

### 1. Анализ сетевых подключений
**Цель:** Изучение базовых сетевых команд Windows для понимания сетевого взаимодействия и отладки.
**Что сделано:** 
- Получил полную конфигурацию сети (IP, DNS, MAC) с помощью `ipconfig /all`.
- Проверил доступность внешних узлов с помощью `ping`.
- Отследил маршрут прохождения пакетов с помощью `tracert`.
- Проанализировал активные сетевые подключения и открытые порты с помощью `netstat`.

### 2. Развертывание изолированной лаборатории (VirtualBox)
**Цель:** Создание безопасной среды для анализа сетевого трафика и тестирования уязвимостей.
**Что сделано:**
- Установлена и настроена платформа виртуализации VirtualBox.
- Развернуты две виртуальные машины: Kali Linux и Windows 10.
- Настроена внутренняя изолированная сеть между машинами.
- Проверено сетевое взаимодействие (пинг) между виртуальными машинами.

### 3. Анализ фишингового письма
**Цель:** Изучение методов социальной инженерии и анализ заголовков электронной почты.
**Что сделано:**
- Проанализированы технические заголовки (Headers) подозрительного письма.
- Проверены записи SPF, DKIM и DMARC на предмет подделки отправителя.
- Проверена ссылка из письма через VirusTotal на наличие вредоносного контента.
- Составлен отчет о признаках фишинга.
