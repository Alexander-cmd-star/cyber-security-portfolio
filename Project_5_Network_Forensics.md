# Проект 5: Анализ сетевого трафика (Network Forensics)

**Цель:** Изучение методов анализа сетевого трафика (PCAP) для выявления признаков вредоносной активности и индикаторов компрометации (IoC).

## Ход работы:
1. **Инструмент:** Использован анализатор трафика Wireshark в среде Kali Linux.
2. **Анализ HTTP:** С помощью фильтра `http.request` обнаружены подозрительные POST-запросы на адрес `/fakeurl.htm`, что характерно для связи с сервером управления (C2).
3. **Анализ IP:** Определен IP-адрес злоумышленника `194.180.191.64`. С помощью фильтра `ip.addr` подтвержден активный обмен данными с данным узлом.
4. **Анализ DNS:** С помощью фильтра `dns` выявлены аномальные запросы к домену `nemotodes.health`, который используется вредоносным ПО для связи.
