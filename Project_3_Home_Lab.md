# Проект 3: Развертывание домашней лаборатории (Киберполигон)

**Цель:** Создание изолированной виртуальной среды для безопасного тестирования инструментов кибербезопасности и анализа сети.

## Ход работы:
1. **Установка гипервизора:** Установлена платформа виртуализации VMware Workstation.
2. **Развертывание Kali Linux:** Скачан официальный образ, успешно импортирован и запущен. Настроен сетевой адаптер.
3. **Развертывание Windows 10:** Установлена виртуальная машина с Windows 10 (в роли условной «жертвы»).
4. **Настройка сети:** Обе машины переведены в режим «Мост» (Bridged), что позволило им получить IP-адреса в домашней сети (Kali: `192.168.0.139`, Windows: `192.168.0.164`).
5. **Настройка брандмауэра:** Создано правило в брандмауэре Windows для разрешения ICMP-запросов (пинга) из внешней сети.
