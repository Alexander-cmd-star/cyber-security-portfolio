# Проект 1: Анализ сетевых подключений

**Цель:** Изучение базовых сетевых команд Windows для понимания сетевого взаимодействия.

## Ход работы:

### 1. Команда `ipconfig /all`
*Зачем:* Получение полной информации о конфигурации сети (IP-адрес, шлюз, DNS, MAC-адрес).
